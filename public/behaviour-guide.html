PLAGUE TALE GO · THE WORKSHOP

Behaviour Guide

Give your pieces small jobs: move, open a door, spread, or react when someone uses them.

Keep this guide beside your workshop tab. Try one behaviour at a time, then combine them.

The first thing to check: some behaviours need an area to work in. Those belong to a parameter, such as Area of effect or Self, rather than directly to an object.

START SMALL

Make one guard move

  1. In Edit, paint a few connected path nodes. Create a Guard token if you need one, then place it on a node.
  2. Select the Guard in the library. In its inspector, choose Behaviours → Add behaviour → Move To. Set Free nodes per turn to 1 and Move towards to Current Move Target. Save behaviours.
  3. Select the placed Guard on the canvas. In its inspector, choose Set move target → Custom position. Enter the column and row of a free node farther along the path, then set the target.
  4. Choose Playtest → Start turn 1. The Guard takes one step. Next turn takes another; Previous turn goes back.

A target is the destination. Move To is the instruction to travel there. You need both for this example.

WHERE TO PUT IT

Object, state, or parameter?

Token / object
A reusable building block in the library: Guard, Player, Lever… A placement is one copy on the canvas. Editing its shared behaviours changes every copy; a placed piece can have its own state switches and move target.
State
A folder inside a token, such as Alive or Dead. A behaviour placed inside Alive works only while Alive is enabled for that piece. It acts through the placed parent object.
Parameter / effect area
A shape attached to a token: Area of effect, Self, Line Effect, Cone Effect, Rectangle Effect, or Cross Effect. It tells an area behaviour where to look. Self covers only the occupied cell, making it useful for overlaps.

Adding an area behaviour

  1. Open the library’s Parameters tab and use + to create a shape. For a nearby interaction, try Area of effect with radius 1.
  2. Attach it to the object: drag the parameter onto the object’s library row, or choose that object in the parameter editor’s Nest inside field.
  3. Select the parameter in the hierarchy, then choose Behaviours → Add behaviour. All seven behaviours are available there.

Turning Alive off also turns off Use inside Reach. A reusable parameter’s settings and behaviours are shared by every object it is attached to.

“Parent object” in the controls means the placed object carrying that behaviour, including behaviours nested inside its states or parameters.

THE DESTINATION IS NOT THE JOURNEY

Set Move Target, step by step

Think of each piece as carrying a little destination note. Set Move Target rewrites that note. It does not move the piece by itself.

InstructionWhat changes?Example
Set Move TargetThe destination a piece remembers“Guard, head toward that noise.”
Move ToThe piece’s position, a few free nodes at a time“Take one step toward your destination each turn.”
TeleportThe piece’s position in one jump“Arrive at the portal’s destination.”

Example: a noise attracts guards

  1. Attach an Area of effect parameter to a Noise token. Put it where the noise can reach the guards.
  2. On that parameter, add Apply Effect. Choose Eligible objects → Selected object types in area, tick Guard, and choose Action → Set Move Target.
  3. Set Move target → Self (the object carrying this effect). Here, Self means the Noise source. Guards caught by its area remember the Noise source as their destination.
  4. On the Guard token, add Move To → Current Move Target, with 1 free node per turn.
  5. Open Behaviour resolution order in Manipulate & Organize. Put the Noise’s Apply Effect before the Guard’s Move To. Test it with Start turn 1.

The Guard travels along a free, connected path. If the Noise object occupies its destination node, the Guard approaches a neighbouring free node. If there is no available route, it stays put.

The three destination choices

  • Self, inside an effect: the object carrying the effect, such as the Noise source above.
  • Custom position: a fixed column and row. Good for “go to this spot.”
  • Other object in the canvas: a particular placed object. Its current position is followed, so this is useful for chasing a moving Player.

Two other uses of “Self”: the Self parameter means “this occupied cell.” In a placed piece’s own inspector → Set move target, Self means “stay here.” In Teleport’s Object to teleport field, Self means the parent placement.

To check a destination: select the placed Guard and find Move target in its inspector. You can also use Set move target there to give one piece a starting destination by hand.

CONNECT A LEVER TO A DOOR

Finding and using Linked Objects

An object link names a relationship between specific pieces on the canvas. A Lever can be linked to a Door across the room. Creating the link gives behaviours a way to find that Door; you still choose what the behaviour does to it.

  1. In Edit, place a Lever and a Door on the canvas.
  2. Choose Link objects (L) in the canvas toolbar, or press L. Click the Lever and Door to include them.
  3. Click Create link, give it a name such as “Door control,” and save the link.
  4. To find it later, select either piece and look for LINKS near the bottom of its inspector, below the patrol colors. Click the link name to inspect it.

Can’t see the connecting line? Select one linked piece, or turn on Show all parameters with the eye button in the small canvas toolbar. Linking objects is separate from nesting tokens in the library and from connecting path nodes for movement.

Try it: click a lever to open and close its door

  1. Give the Door Closed and Open states. In the Door inspector, enable Mutually exclusive states and turn Closed on.
  2. Attach an Area of effect parameter to the Player. Select that parameter and add Use and Apply Effect.
  3. In Usable objects, choose selected object types and tick Lever. In Apply to, choose Clicked object’s Linked Object(s).
  4. Choose Action → Switch State, select or type Open, and set Switch → Toggle mutually exclusive states. Save behaviours.
  5. In Playtest, move the Player close enough to the Lever. Click its little hand badge: the linked Door opens. Click again to close it. Clicking the Lever’s body still selects it.

PICK THE JOB YOU NEED

The seven behaviours

Open a card for the important choices and a small example.

Expand Parameter only · Turn start

“Make more copies here.” Copies the placed parent and its hierarchy onto highlighted path nodes. Try spreading a rat swarm from a small Area of effect.

It normally skips nodes that already contain that object type. Allow copies where this object type is already present permits stacking instead. New copies first act next turn. Expansion stops with an error if the level would exceed 1,000 pieces.

Apply Effect Parameter only · Turn start

“Find these objects and do this to them.” First choose Eligible objects: any type in the area, selected library types, or Linked Object(s). Then choose an Action.

Example: an Area of effect around a fire sends matching rats to the Graveyard. An empty selected-types list affects nothing. The parent itself and parameter markers are excluded from area targets.

Block Node Parameter only · Always while active

“These nodes are off limits.” Choose Block for all objects or selected types. Movement only blocks travel; Movement and other effects also makes the nodes act like walls for effects cast by those chosen types, stopping areas on and beyond them.

Exclude Self lets the parent ignore its own blocker. Other copies are still blocked, and other blockers can still affect the parent. Only highlighted cells containing path nodes are blocked.

Example: put the blocker under a Door’s Closed state. Opening that Door disables that blocking branch immediately, without waiting for a turn.

Use and Apply Effect Parameter only · Hand click

“Let the player interact with something nearby.” Choose Usable objects, decide whether Apply to means the clicked object or its linked objects, then choose an Action.

A small hand appears on usable objects in range during Playtest. Click the hand to use; click the body to select. If several actions or stacked usable pieces are available, a choice list appears. Range and active states are checked again when you click.

Use does not run by itself at turn start. Add Advance Turn On Event with Use selected if using something should also take a turn. The lever-and-door example shows the full setup.

Move To Token, state or parameter · Turn start

“Walk a few steps toward a destination.” Free nodes per turn is the maximum number of connected, unoccupied nodes to travel. A missing destination or unavailable route means no movement. Broken connections, active objects, Block Node, and scenery locks can stop it.

Choose Current Move Target for a destination remembered by the piece. Use Set Move Target or its placement inspector to supply that destination.

For a patrol, choose Patrol Start → End → Start or the reverse, then select a saved patrol or match the piece’s patrol color dot. The piece joins the chosen endpoint if needed, follows the saved route, and turns back at each end. This patrol choice uses the patrol rather than Current Move Target.

Teleport Token, state or parameter · Turn start

“Jump straight to a destination.” Choose Object to teleport: Self means the parent placement, or select another canvas piece. Then choose a specific column/row, a selected canvas object, or a linked object as the destination.

For Linked object, choose a destination directly linked to the piece being teleported, or leave the choice on the first linked object in saved link order. Arriving in the destination object’s occupied cell is allowed. Missing destinations, walls, out-of-bounds cells, movement blockers, and scenery locks can prevent the jump.

Teleport is also an Action inside Apply Effect and Use. There, the affected objects are the ones teleported.

Advance Turn On Event Token, state or parameter · User action

“This action spends a turn.” Tick one or more events for the parent: Use, Object Moved, Object Added To Inventory, or Object Dropped from Inventory.

Moved includes a successful user drag/drop or arrow-key move. Inventory events mean manual backpack collection or placement. Use counts for both the acting parent and the clicked usable object. One user action advances at most one turn, even if it matches several events.

Rotation, failed moves, Graveyard transfers, and initial inventory loading do not spend a turn. Automated turn actions do not start another turn. Previous also undoes the user action that triggered the turn.

WHAT HAPPENS TO THE TARGET?

The Action inside Apply Effect or Use

The behaviour decides when and whom. Its Action decides what happens to the affected object.

ActionPlain-language meaningWhat to choose
Switch State“Become Open, Lit, Dead…”Select a state from suggestions, or type its name to match a state in each affected object. Enable or disable it. Only that placement changes.
Send to Graveyard“Remove this piece from play.”Choose which objects the behaviour affects. Their individual states are preserved; drag them back from the Graveyard to restore them.
Set Move Target“Remember this destination.”Self, a fixed position, or another canvas object. Pair it with Move To → Current Move Target. See the full example.
Flush“Remove this continuous chain.”A caught object starts a chain through horizontally/vertically touching active pieces of the same type, including stacks. Gaps, other types and effect blockers stop it.
Teleport“Move this piece there in one jump.”A specific cell, selected canvas object, or linked destination. No Move To behaviour is needed.

Opening and closing with Toggle

For states such as Open and Closed, enable Mutually exclusive states on their parent token. In a Use Switch State action, choose Switch → Toggle mutually exclusive states. Repeated uses alternate two states, or cycle a larger sibling group in library order. The chosen state identifies the group and is enabled first if none is active. Non-exclusive groups and single-state groups are skipped.

Choosing Flush reach

Max flush reach → Infinite follows the chain until it ends. Limited counts continuous cells from each initially caught cell, including that cell:

  • 1: only the initially caught cells.
  • 2: those cells plus one adjacent step along the chain.
  • 3: up to two adjacent steps, and so on.

For a line of rats A–B–C, if only A is initially caught, reach 2 removes A and B. A gap before D keeps D safe. Stacked pieces share a cell; each branch follows the same reach limit. Flush works through touching pieces even where there are no path nodes.

PUT THE PIECES TOGETHER

Turns, states, and resolution order

Set up behaviours in Edit, save them, then choose Playtest. The board is a private copy. It starts at Ready to start; Start turn 1 runs turn-start actions. Blockers are already live, and Use waits for a hand click.

Open Behaviour resolution order in the collapsible Manipulate & Organize panel, use the canvas ⇅ button, or choose Resolution order in the inspector. Move actions up or down with the arrows.

Order changes the result. A Noise that sets targets before Guards move lets them react that turn. Switching Alive off before a Move To nested inside Alive stops that move. Actions read the states and positions left by earlier actions. Newly expanded copies wait until the next turn.

Use Resolution log to see what ran and the affected counts. Previous turn restores positions, states, targets and backpack contents. Save a sequence before leaving Playtest if you want to keep it.

Starting with items? Use Level settings → Player’s starting inventory. Quantity 0 means an unlimited stack. Starting items load before turn 0 and do not trigger Advance Turn On Event. Reset restores them; later manual inventory transfers can spend a turn.

QUICK CHECKS

Something isn’t happening?

“The behaviour isn’t in the list.”
Check the availability table. Select the attached parameter, rather than its parent token, for Expand, Apply Effect, Block Node, or Use.
“My guard has a target but won’t move.”
Add Move To and choose Current Move Target. Check connected free nodes, Block Node, broken connections, and scenery locks. Then start or advance a turn.
“There’s no hand on the lever.”
Use belongs on a parameter. Attach that parameter to the acting object, choose Lever as usable, enter Playtest, and bring the Lever into range. Check enabled states and blockers.
“The lever is in range, but the door doesn’t open.”
Link the placed Lever and Door. In Use, choose Apply to → Clicked object’s Linked Object(s), then Switch State with an existing Door state.
“Toggle does nothing.”
It is a Use Switch State option. The chosen state needs at least one sibling, and their parent needs Mutually exclusive states enabled.
“Nothing is eligible.”
Tick at least one object type in a selected-types list. A chosen type applies to its placed copies; a selected canvas object means one particular piece.
“A whole branch has stopped.”
An inactive state suppresses all behaviours nested inside it. Inspect the placed piece’s state switches, not just the library defaults.
“The controls disappeared in Projector view.”
Use Show / hide at the top right. Enable Tools or Parameters / Patrols / Resolution Order. Inventory and Graveyard have their own switches.
